# Portfolio Case Study: Drawing QA Agent
### Automated Drawing-Set Verification with Guardrailed AI Agents

---

## The Challenge
Architectural coordination across plan geometry, area statements, callouts, and door/window schedules is traditionally error-prone and labor-intensive. When reviewing construction documentation sets, inconsistencies between drawn geometry and tabular schedules frequently lead to contractor RFIs, variation claims, and on-site delays. While Large Language Models can assist in drafting review notes, applying generative AI directly to drawings risks hallucinations, invented dimensions, and untrustworthy compliance claims.

---

## The Solution
**Drawing QA Agent** is an automated drawing-set review system grounded in the design philosophy:
> **"AI proposes, code checks, people approve."**

Instead of asking an LLM to "inspect" drawings directly, the system structures architectural drawing packages into machine-readable vector geometry (via Shapely) and tabular schedules (via pandas). It runs 13 pure deterministic validation rules (R01–R13), then uses a **LangChain tool-calling agent** to synthesize findings and generate actionable review notes.

A deterministic **code guardrail** intercepts all agent outputs, strictly dropping any finding not generated by a registered tool (`rejected_unsupported`) and restoring any altered evidence. The system separates findings into two distinct categories:
1. **RULE FAILED (Objective, code-measured):** Arithmetic sum mismatches, polygon vs. schedule area discrepancies, broken callout references, and missing tags.
2. **NEEDS HUMAN REVIEW (Judgement & design intent):** Narrow room aspect ratios (> 3:1), non-standard room naming variants, and geometry overlaps.

## System Architecture

```
┌────────────────────────────────────────────────────────┐
│               Drawing Package Input Folder              │
│  brief.json │ rooms.csv │ area_stmt.csv │ sheets.csv   │
│  callouts.csv │ openings.csv │ opening_schedule.csv    │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│           Deterministic Rule Suite (src/checks.py)      │
│  • Shapely vector geometry checks (areas, overlaps)    │
│  • Pandas tabular joins & arithmetic verifications     │
│  • Fuzzy room name reconciliations                     │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│         LangChain Tool-Calling Reviewer Agent           │
│  • Tools: check_R01 ... check_R13, get_summary         │
│  • Generates architectural synthesis & review notes     │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│            Code Guardrail ("Code Checks")              │
│  • Verifies finding IDs against executed tool logs     │
│  • Drops hallucinated findings (rejected_unsupported)  │

└──────────────────────────┬─────────────────────────────┘
                           │

┌────────────────────────────────────────────────────────┐

│  • Streamlit Web Dashboard (app.py)                    │
└────────────────────────────────────────────────────────┘
```

## Key Technical Highlights
- **Deterministic Independence (`--no-llm` mode):** Works entirely offline with zero API keys or external network dependencies for CI/CD and air-gapped environments.
- **Configurable Tolerances (`rules.yaml`):** Area discrepancy percentages, fuzzy naming thresholds, and aspect ratios are fully externalized without code edits.
- **Visual CAD Redlining:** Matplotlib rendering engine automatically paints failing rooms with red boundaries and rule labels directly on the drawing plan.
