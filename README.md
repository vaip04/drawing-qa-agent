# Drawing QA Agent · Project 2

### An AI drawing-set reviewer: checks a set against its brief, separates "rule failed" from "needs human review", never edits drawings

> **Core Philosophy:** *AI proposes, code checks, people approve.*

---

## 1. What It Does

Given an architectural **drawing package** (project brief, area statement, room vector geometry, sheet index with callouts and revisions, and door/window tags and schedules), the **Drawing QA Agent**:
1. Runs deterministic pure Python geometric & tabular checks.
2. An agent reviews the package findings, keeping factual evidence strictly intact.
3. Groups every observation into two actionable tiers:
   - **`RULE FAILED` (Objective, Code-Measured):** Discrepancies between polygon geometry and written area statements, schedule size mismatches, broken callout references, sheet revision mismatches, un-dimensioned rooms, and brief limit breaches.
   - **`NEEDS HUMAN REVIEW` (Judgement & Design Intent):** Usability flags such as narrow passage aspect ratios (> 3:1), subtle naming variants (e.g. "Mstr Bed" vs "Master Bedroom"), and geometric overlaps requiring architectural sign-off.
4. **Code Guardrail:** Enforces that findings not generated by code checks are dropped (`rejected_unsupported`), and any tampered values or evidence are restored to ground-truth values.
5. **Never Edits Drawings:** Read-only analysis ensuring drawing integrity.

## 4. Quickstart & How to Run

### Installation
```bash
# Clone the repository
git clone https://github.com/patidarvaibhav/drawing-qa-agent.git
cd drawing-qa-agent

# Create Python 3.12 virtual environment & install dependencies
python -m venv .venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Running Reviews

**1. Deterministic Review (No API key needed, never fails):**
```bash
python run.py --package demo_seeded --no-llm
```

**2. Run All Packages:**
```bash
python run.py --all --no-llm
```

**3. Run with LLM Tool-Calling Agent:**
Ensure `GOOGLE_API_KEY` is set in `.env`, then:
```bash
python run.py --package demo_seeded
```

**4. Run Automated Evaluation Benchmark:**
```bash
python evaluate.py --no-llm
```

**5. Launch Streamlit Web UI:**
```bash
streamlit run app.py
```

## 5. Limitations
1. **Synthetic 2D Packages:** Test suites use 2D Cartesian polygon approximations rather than 3D IFC/BIM solid geometry models.
2. **Project Rules vs. Statutory Codes:** Rule thresholds reflect project-specific brief constraints, not statutory municipal building bylaws (e.g. NBC, IBC).
3. **Static Review Scope:** Validates drawing packages at a given freeze point; does not track live real-time BIM model streams.
